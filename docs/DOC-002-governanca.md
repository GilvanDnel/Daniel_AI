# DOC-002 - Governança do Conhecimento

## Regras

1. Documentos oficiais só podem ser adicionados pelo administrador.
2. Documentos confidenciais não devem ser indexados.
3. Arquivos temporários do usuário não entram na base corporativa.
4. Daniel não deve inventar respostas.
5. Respostas institucionais devem citar fonte quando houver documento recuperado.
6. Pedidos sem resposta suficiente devem ser encaminhados ao setor responsável.

## Classificação

| Classificação | Entra na base? | Exemplos |
|---|---|---|
| Pública interna | Sim | Política de férias, FAQ, manual de atendimento. |
| Restrita | Futuro, com permissão | Relatórios gerenciais e contratos. |
| Confidencial | Não | Salários individuais, dados médicos, dados bancários. |
