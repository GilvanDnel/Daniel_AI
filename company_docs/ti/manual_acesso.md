# Manual de Acesso - DNEL SOM Serviços Inteligentes

**Documento:** TI-001  
**Classificação:** Pública interna

## Solicitação de acesso

Solicitações de acesso a sistemas internos devem ser abertas para o suporte de TI, com aprovação do gestor imediato.

## Problemas técnicos

Falhas de VPN, sistemas ou permissões devem ser comunicadas pelo e-mail suporte.ti@dnelsom.com.br.
